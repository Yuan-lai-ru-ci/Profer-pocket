# 抽屉导航：状态条、项目收起与项目置顶（2026-11-02）

目标：手机抽屉的层级与桌面侧栏对齐，不再用一个状态点 + 全展开项目凑出一屏。

## 1. 会话状态挪到行首

- 右侧「运行中/未读」小点删除，改成行首 3dp 竖条 + 行底色（`onSurface` 4%）。
- 状态口径对齐桌面 `SessionIndicatorStatus`：**等人确认（warning）> 运行中（info）> 未读（success）**。
  - 新增 `ProferSemanticColors.info`（浅色 `#3A6B8A` / 深色 `#8FB8D4`）：桌面的运行态是蓝色，
    手机之前用 success 绿，会和「已结束未读」撞色。
  - 未读不再用品牌陶土色：竖条会被误读成「选中行」。
- 「等人」来自 `repository.chats` 的 `pendingInteraction`（`waitingSessionIds`），
  只有已加载的会话知道；未知时按运行中/未读显示，不猜。
- 子会话行不加竖条，左侧分支图标按同一状态上色（与桌面同一分层）。
- 状态同时写进 `stateDescription`（「等待你的确认 / 运行中 / 未读」），颜色不是唯一信息载体。

## 2. 项目不再全展开

- 首屏只展开「当前会话所在项目」；没有当前会话时展开最近活动的项目。置顶项目不会替用户展开。
- 项目内默认只铺预览：常显项目内置顶、运行中/等人/未读、当前会话（含「当前打开的是子会话」），
  其余按目录顺序补足到 `PROJECT_PREVIEW_LIMIT = 5`。
  - 桌面预览上限是 8，那是在 ~900px 高的窗口里铺；手机上 8 条吃掉半个抽屉。
  - 剩余 ≤ 2 条时直接铺完，不出现「显示更多（1）」。
- 超出的收进「显示更多（N）」行，展开后给「收起已展开的会话」；收起项目头会一并复位。
- 搜索时（`forceExpand`）全部铺开，不受预览限制。

## 3. 置顶只做项目置顶

- `SessionCatalog` 不再产出跨项目「置顶」组：置顶会话留在所属项目内，排在最前并带行首图钉
  （与桌面项目内排布一致）。
- 项目置顶：项目行升到列表最前，标题旁显示置顶徽标（品牌色小圆底 + 图钉）；长按项目头可置顶/取消。
- 会话菜单文案改为「置顶（项目内）/ 取消置顶（项目内）」，避免和项目置顶混淆。

## 验证

- 单测：`ProjectSessionWindowTest` 8 例（预览上限、活动常显、当前会话保留、尾巴阈值、展开/收起）；
  `SessionCatalogTest` 更新置顶相关 4 例；`./gradlew test` 全绿。
- 真机（1080×2344 / 480dpi，debug 画廊 `page=sessions`）：
  浅色 / 深色 / 1.3× / 2.0× 截图在 `screenshots/2026-11-02-sidebar/`。
- 交互实测：项目折叠→展开回到预览态；「显示更多」展开→「收起」；项目长按菜单「取消置顶项目」；
  会话长按菜单「取消置顶（项目内）」。
- 未验：真实桌面端 875 条会话下的首屏表现（本机没有可用的配对凭据，用画廊样本 + 单测覆盖规则）。
